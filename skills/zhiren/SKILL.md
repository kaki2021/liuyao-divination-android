# 知人 Skill（MVP）
此 Skill 的数据存于运行设备的 zhiren.sqlite3，与六爻案例、占问历史和规则包隔离。

## 能力
- 查询人物档案、技能、兴趣、所在城市与近期需求。
- 根据活动或合作需求请求人物匹配，并向用户说明匹配的实际依据。
- 将需求、动态、倡议、活动保存为本地草稿，保留用户勾选的拟通知名单。
- 保存自定义名片字段模板与适用关系说明。

## 工具契约（APP 本地接口）
- GET /api/zhiren/people
- POST /api/zhiren/people
- POST /api/zhiren/match
- GET /api/zhiren/posts
- POST /api/zhiren/posts
- GET /api/zhiren/cards
- POST /api/zhiren/cards

## 必须遵守
- 先检索，再给出可追溯的匹配理由；没有证据就说明没有证据。
- AI 生成的摘要不得覆盖原始人物记录。信息有时间性，不应假定对方现在有空。
- 不读取六爻占问历史，也不自动共享本人或其他人的私密资料。
- 发布、勾选名单不等于已经通知。当前接口只能生成未发送的草稿。
- 实际对外消息、好友名片交换、跨 Skill 读取均需要独立授权和独立实现。
- 不调用网络模型处理人物资料，除非用户明确允许并能检查发送内容。

## 后续扩展
人物照片、动态入库后的语义检索、事件中心、跨终端加密通信、共享 Profile、AI 调度与标准 MCP 适配层。本阶段不宣称已实现。
