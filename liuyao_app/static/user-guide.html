新人使用说明

写清问题 → 记录起卦结果 → 保存并分析 → 查看结论和条件 → 记录实际进展。

内置规则版安装后即可排盘、保存案例。AI 解卦需要联网，并在“模型设置”中填写自己账户的 API 密钥。

1. 第一次打开：先设置模型

  1. 打开右上角“模型设置”，选择 AI 厂商和模型。
  2. Android 版点击“配置 API 密钥”，填入对应厂商提供的密钥并保存，再点击“使用此设置”。密钥由应用加密保存在本机。
  3. DeepSeek 可选模型以界面实际列表为准；豆包需填写自己已开通的模型或接入点。API 调用费用由所选厂商按账户规则计收。

只想记录和查看卦盘，可以先不配置 AI，使用“保存并排盘”。“离线演示”只展示流程和计算，不会给出 AI 解卦结论。

2. 写下一个清楚的问题

写明在问谁、什么事、想判断什么，以及相关时间范围；有必要的背景再补充。一次围绕一个主问题展开。

例如：“我正在考虑接受 A 公司的录用，想问未来三个月这份工作是否适合我。已知薪资和工作地点，团队情况还不清楚。”

  • 区分“事情能否办成”和“办成后对我有没有好处”，可以写清主要关注点。
  • 起卦时间填写实际起卦时刻；补录旧卦时不要误填成现在。不知道的时间保持未知。
  • 人物档案可选填，便于后续重复使用。出生资料目前用于记录与八字辅助展示。
  • 涉及住处时，可选择卜宅专题并按页面提示说明是择地、选房还是核对现有住处。

3. 按你使用的方式记录卦象

推荐使用实物起卦：太极丸、枚卜丸、蓍草与筹策。软件也提供“随机模拟掷币”作为便捷选项；记录中会注明模拟来源。

点击“下一步 · 记录卦象”，选择与你实际操作一致的录入方式。旁边的“怎么记录？”可随时打开对照表。

蓍草／筹策：独立记录十八变

这里按本软件采用的筹策流程说明。筹策可以使用蓍草，也可用竹签或木筹。选择独立的“蓍草／筹策”入口；每变完成后，按实际左右次序选余策组合。软件自动判阴阳，三变合成一爻，保留六爻十八变的原始记录。

  1. 准备：共备 60 根，先留出 5 根，再从取出的 55 根中留出 6 根，以余下 49 根操作。把其中一根标记为阴阳签。
  2. 分二、挂一：将 49 根放入筒内摇匀，取出铺开，以阴阳签的位置分成左右两部分；取出阴阳签，作为本变“挂一”的一根。
  3. 揲四：两侧分别按四根一组分出。每个非空部分最后保留 1—4 根作为余策，正好四根时保留四根；空的一侧记 0。将两侧余策分开放置，保留这一变的组合。
  4. 判这一变：两侧余策为 1 与 3、3 与 1，或一侧 0、另一侧 4，记为阳象 3；余策为 2 与 2、4 与 4，记为阴象 2。
  5. 继续下一变：将两侧余策留在旁边，把挂起的阴阳签放回刚才分出的其余筹策中，再重复分二、挂一、揲四。第一变后应剩 45 或 41 根，第二变后应剩 41、37 或 33 根。
  6. 三变合爻：三次全阴是老阴，两阴一阳是少阳，一阴两阳是少阴，三次全阳是老阳。三变先后次序会留存，最终爻象由阴阳数量确定。
  7. 复原再起下一爻：核对页面自动生成的爻象，收回这一爻的全部余策，恢复 49 根，点击“下一爻”继续。依次完成六爻，共十八变。

本流程依据每一变的“两侧余策组合”判阴阳，挂起的一根会放回下一变使用。请完整沿用这一流程；不能把别的筮法中“挂一另置”或“最后剩余根数除以四”的步骤混入。

例如三变依次得到“1 与 3”“0 与 4”“4 与 4”，就是阳、阳、阴，记作 332，软件自动合成“少阴”。

页面逐变显示应取的根数和记录后的剩余根数，供你核对实物；这些数由录入结果推算，不能代替实物计数。点上方爻位和“第几变”可返回更正，后续根数提示会重新计算。

未记录满十八变不能保存成完整卦例。Android 版会保留尚未保存的输入；返回后先核对记录，再接着操作。保存后，在卦盘页、重新编辑和导出案例中都能查到十八变原始余策。若只保留了最终六爻，请使用“逐爻录入”。

逐爻录入：硬币、已有六爻结果

用硬币起卦，或已有六个爻的完整结果时，选择“逐爻录入”。蓍草／筹策要逐变记录时，使用独立入口；只抄录最终六爻也可在这里完成。每得到一爻，就在对应位置选择老阴、少阳、少阴或老阳，共录入六爻。

第一次得到的是初爻，第六次得到的是上爻。按页面的初爻、二爻至上爻依次填入；卦盘展示时，上爻在上、初爻在下。老阴、老阳是动爻，少阴、少阳是静爻。

硬币／铜钱：三枚一起投掷，共六次

准备三枚同规格钱币。本软件采用的阴阳面认定是：承载面值、年号等主要识别信息的一面为阴，另一面为阳。例如清代铜钱的汉字面为阴、满文面为阳；一元硬币的“一元”面为阴，另一面为阳。先辨明两面，再按同一规则记录六次。

每次三枚一起投掷，只看朝上的一面。阴面记 2，阳面记 3；对照下表，直接选择这一爻：

朝上的三面记数选择
三阴222＝6老阴，动，变阳
两阴一阳223＝7少阳，静
一阴两阳233＝8少阴，静
三阳333＝9老阳，动，变阴

三枚的排列顺序不影响这一爻。例如第一次得到“两阴一阳”，就在初爻选择“少阳”，然后再投掷并填写二爻。

已有卦象：逐爻抄录阴阳动静

按原始记录填写六个爻象；只有本卦名称或阴阳线条时，还需要确认哪些爻发动。静爻填少阴或少阳，动爻填老阴或老阳。只有本卦名时，不应擅自把六爻都设成静爻。

随机模拟掷币：每次三枚，共六次

  1. 先写清问题，进入“记录卦象”，选择“随机模拟掷币”。
  2. 点击“模拟第 1 次 · 初爻”，页面显示三枚币各自的阴2或阳3及本爻阴阳动静。
  3. 继续点击，共六次，从初爻到上爻依次成卦。每次结果立即留在列表中，齐六爻后可保存并排盘或分析。
  4. 首次模拟时，起卦时间未填则记录当前时刻；已填写的时间保留你的设置。补录实物旧卦时，请使用相应录入入口。

切换起卦方式再切回来、中途恢复草稿、保存或重新解卦，都不会重新抽取已有结果。软件保留“随机模拟”标记和全部六次三枚币原始结果。要另起一卦，请使用“新建系列”或原系列的“再起一卦”。

随机原理与概率

本入口用系统随机数模拟三枚公平、独立的硬币。采用浏览器的 crypto.getRandomValues 提供强随机值，通常由系统熵源驱动的伪随机发生器产生；它不是实际投掷硬币，也不意味着具有预测能力。

数学模型：每枚阴面记 2、阳面记 3，设 X₁、X₂、X₃ 各以 1/2 概率取 0 或 1，且相互独立，则总数 S＝6＋X₁＋X₂＋X₃。故 P(S＝6＋k)＝C(3,k)／8（k＝0、1、2、3）。

结果对应爻象理想概率
6老阴1/8＝12.5%
7少阳3/8＝37.5%
8少阴3/8＝37.5%
9老阳1/8＝12.5%

不能把四种爻象各按 25% 随机选取后称为“三枚硬币模拟”；实物硬币也可能存在偏差。上表仅描述公平硬币模型，不代表本软件筹策法的概率。

概率分布可用数学和抽样检验核对，预测现实事件是否准确则要另做预先规定判断标准、对照基准并可重复的验证。已有易经相关实验，但所查资料不足以证明软件随机起卦能可靠预测现实事件；一项 200 人研究中仅第二卦命中率高于机会水平，且差异并不显著，也不能据此宣称实际预测准确率。

推荐使用太极丸、枚卜丸、蓍草与筹策进行实物起卦。随机模拟作为便捷选项，不能据此宣称预测准确率；录入、换算与排盘测试通过，表示程序步骤符合相应规则。

原理参考：W3C 随机值接口；Storm（2006）易经实验。

4. 保存、分析与等待

  • 保存并排盘：保存问题和卦象，查看本卦、变卦及程序计算。
  • 保存并分析：保存后调用所选模型，依次理解问题、确定取用、综合解卦，最后由本机整理报告。
  • 需要补充：按模型提出的问题补充真实背景，再继续分析。保留不确定事项，不必为了凑齐信息而猜测。

分析时可查看当前阶段、已用时间和 Log。高强度推理可能需要较长时间，尽量保持网络稳定；手机若严格限制后台运行，可把应用留在前台。点击“刷新状态”只查询当前任务。

“重新解卦”会新建一次分析，并重新调用模型，可能产生新的 API 费用。只有补充了信息、希望重新判断或前面步骤确实失败时再使用。

5. 三个结果页面怎么看

页面主要看什么
解卦结论本次回答、成立条件、需要留意的事项及后续建议。
专业分析问题理解、取象选择、爻的状态、判断依据和不确定之处。
卦盘与计算本卦、变卦、动爻、干支、六亲、世应及程序计算结果。

结论应连同条件和边界一起看。软件中的“未知”“待核实”表示资料不足或条件尚未确定；“有条件成立”需要同时满足列出的条件。

6. 追问、再起一卦和档案

  • 沿用当前卦：打开已有卦例，补充背景或发送追问，围绕该卦继续分析。
  • 再起一卦：需要新卦时，从所选卦下发起，重新记录起卦结果。新卦会保留在同一系列中。
  • 新建系列：用于独立的新问题。
  • 档案：查找以前的系列，展开后打开其中的任意一卦。系列可以共享有来源的背景，各卦保留各自的问题、卦象、时间和分析。

事情有进展后，点击“记录后续反馈”，写下实际发生的结果与时间，便于之后复盘。

7. 导出与备份

在结果页使用“导出案例”，或在系列中导出整个系列。发送问题给维护者时，可附“导出诊断”，并说明使用的厂商、模型、卡住的阶段和出现时间。

案例和配置主要保存在当前手机中。卸载、清除应用数据或换手机前先导出；目前导出用于留存和复盘，尚无一键恢复整个旧档案的入口。若安装的是独立新版，应保留旧应用以便查阅已有案例。

在软件的“使用说明”窗口点击“导出说明”，可保存成 HTML 文件，发给新人后用浏览器打开即可。

8. 遇到问题时

提示或现象处理方式
旧报告提示“报告整理超时”先查看已保留的结论与“专业分析”，不必仅为这条提示重新解卦。新版在综合解卦完成后由本机整理报告。
前面的 AI 阶段超时检查网络、厂商服务和账户额度，查看 Log；确认任务已结束后再重新解卦。
密钥或权限错误检查密钥对应的厂商、账户可用额度，以及是否开通了所选模型。
回复格式未通过校验应用会尝试修复并保留原回复；仍失败时导出诊断，便于定位具体字段。
尚未安装规则包确认安装的是“内置规则版”。公开源码构建的版本需要在“规则 → 规则包”中另行导入。

先记录真实问题和实际卦象，再结合条件阅读结果；后续发生的事实也保存下来，才能形成有用的案例。
