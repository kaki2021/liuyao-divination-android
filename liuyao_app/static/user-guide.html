新人使用说明

从第一卦开始，按需要查阅。

第一卦，从这里开始

只想排盘可以直接开始；AI 解卦需要先配置密钥。

  1. 写下一个明确的问题

    说明对象、打算和犹疑之处，必要时补充时间范围与背景。

  2. 选择方式，记录卦象

    进入“记录卦象”，在下拉框选择实际使用的器具。初次使用可点“操作图解”。

  3. 保存，然后看结论与条件

    “保存并排盘”用于留存和计算；“保存并分析”会调用 AI。事情有进展后，补上实际反馈。

首次使用：怎样配置 AI 模型？
  1. 打开右上角“模型设置”，选择厂商和模型。
  2. Android 版点击“配置 API 密钥”，填写对应厂商提供的密钥，保存后点“使用此设置”。密钥加密保存在本机。
  3. 可选模型以页面实际列表为准；豆包需填写已开通的模型或接入点。API 费用按所选厂商账户规则计收。

“离线演示”只展示流程和计算，不会给出 AI 解卦结论。

问题怎么写？哪些资料需要填？
内容填写要点
这次的所问问谁、什么事、拿不准什么；需要时说明时间范围。
背景与人物只补充与本问有关的已知事实。人物档案选填，出生资料用于记录与八字辅助展示。
实际起卦时间填写真正起卦的时刻；补录旧卦时不要误填现在。未知则留空。
卜宅专题按提示选择择地、选房或核对现有住处，并说明范围。

提问示例

我正在考虑接受 A 公司的录用，想问未来三个月这份工作是否适合我。已知薪资和工作地点，团队情况还不清楚。

先认真考虑现实条件，再问尚未拿准之处。“能否办成”和“办成后是否有利”可以区分；排查问题时，先明确待查对象、范围与目的。

推荐实物起卦：太极丸、枚卜丸、蓍草与筹策。
选择一种方式，查看对应步骤与图解。

太极丸

每次记录三颗丸的数字，共六次。

每摇一次，就在对应行选数字组合；第一次是初爻，第六次是上爻。同组数字的排列次序不影响选择，232 与 322 均选 223。

三颗数字爻象动静
222老阴 ×动，变阳
223少阳静，阳爻
233少阴静，阴爻
333老阳 ○动，变阴

六行都填写后保存。若只记住最终的阴阳动静，可选择“逐爻录入”。

蓍草／筹策

六爻十八变，逐变保留左右余策。

这里按本软件采用的筹策流程说明。筹策可以使用蓍草，也可用竹签或木筹。选择独立的“蓍草／筹策”入口；每变完成后，按实际左右次序选余策组合。软件自动判阴阳，三变合成一爻，保留六爻十八变的原始记录。

实物操作：准备、分二、挂一、揲四
  1. 准备：共备 60 根，先留出 5 根，再从取出的 55 根中留出 6 根，以余下 49 根操作。把其中一根标记为阴阳签。
  2. 分二、挂一：将 49 根放入筒内摇匀，取出铺开，以阴阳签的位置分成左右两部分；取出阴阳签，作为本变“挂一”的一根。
  3. 揲四：两侧分别按四根一组分出。每个非空部分最后保留 1—4 根作为余策，正好四根时保留四根；空的一侧记 0。将两侧余策分开放置，保留这一变的组合。
  4. 判这一变：两侧余策为 1 与 3、3 与 1，或一侧 0、另一侧 4，记为阳象 3；余策为 2 与 2、4 与 4，记为阴象 2。
  5. 继续下一变：将两侧余策留在旁边，把挂起的阴阳签放回刚才分出的其余筹策中，再重复分二、挂一、揲四。第一变后应剩 45 或 41 根，第二变后应剩 41、37 或 33 根。
  6. 三变合爻：三次全阴是老阴，两阴一阳是少阳，一阴两阳是少阴，三次全阳是老阳。三变先后次序会留存，最终爻象由阴阳数量确定。
  7. 复原再起下一爻：核对页面自动生成的爻象，收回这一爻的全部余策，恢复 49 根，点击“下一爻”继续。依次完成六爻，共十八变。
左右余策本变记数
1｜3、3｜1、0｜4、4｜0阳象 3
2｜2、4｜4阴象 2

本流程依据每一变的“两侧余策组合”判阴阳，挂起的一根会放回下一变使用。请完整沿用这一流程；不能把别的筮法中“挂一另置”或“最后剩余根数除以四”的步骤混入。

图中三变依次得到“1 与 3”“0 与 4”“4 与 4”，记作 332，自动合成少阴。

在软件里怎么记

页面逐变显示应取的根数和记录后的剩余根数，供你核对实物；这些数由录入结果推算，不能代替实物计数。点上方爻位和“第几变”可返回更正，后续根数提示会重新计算。

未记录满十八变不能保存成完整卦例。Android 版会保留尚未保存的输入；返回后先核对记录，再接着操作。保存后，在卦盘页、重新编辑和导出案例中都能查到十八变原始余策。若只保留了最终六爻，请使用“逐爻录入”。

逐爻录入

适合硬币起卦，也适合抄录已有的六爻结果。

用硬币起卦，或已有六个爻的完整结果时，选择“逐爻录入”。蓍草／筹策要逐变记录时，使用独立入口；只抄录最终六爻也可在这里完成。每得到一爻，就在对应位置选择老阴、少阳、少阴或老阳，共录入六爻。

第一次得到的是初爻，第六次得到的是上爻。按页面的初爻、二爻至上爻依次填入；卦盘展示时，上爻在上、初爻在下。老阴、老阳是动爻，少阴、少阳是静爻。

用三枚硬币起卦

准备三枚同规格钱币。本软件采用的阴阳面认定是：承载面值、年号等主要识别信息的一面为阴，另一面为阳。例如清代铜钱的汉字面为阴、满文面为阳；一元硬币的“一元”面为阴，另一面为阳。先辨明两面，再按同一规则记录六次。

每次三枚一起投掷，只看朝上的一面。阴面记 2，阳面记 3；对照下表，直接选择这一爻：

朝上的三面记数选择
三阴222＝6老阴，动，变阳
两阴一阳223＝7少阳，静
一阴两阳233＝8少阴，静
三阳333＝9老阳，动，变阴

三枚的排列顺序不影响这一爻。例如第一次得到“两阴一阳”，就在初爻选择“少阳”，然后再投掷并填写二爻。

只有已有卦象，怎么抄录？

按原始记录填写六个爻象；只有本卦名称或阴阳线条时，还需要确认哪些爻发动。静爻填少阴或少阳，动爻填老阴或老阳。只有本卦名时，不应擅自把六爻都设成静爻。

随机模拟掷币

每次三枚，共六次，从初爻到上爻。

  1. 先写清问题，进入“记录卦象”，选择“随机模拟掷币”。
  2. 点击“模拟第 1 次 · 初爻”，先播放约 2 秒的翻转落币动画；动画结束后才生成随机数，显示三枚币各自的阴2或阳3及本爻阴阳动静。
  3. 继续点击，共六次，从初爻到上爻依次成卦。每次结果立即留在列表中，齐六爻后可保存并排盘或分析。
  4. 首次模拟完成时，起卦时间未填则记录当前时刻；已填写的时间保留你的设置。补录实物旧卦时，请使用相应录入入口。

动画中途切换方式、离开当前页面或把软件切到后台，本次掷币取消，不生成结果。切换起卦方式再切回来、中途恢复草稿、保存或重新解卦，都不会重新抽取已有结果。软件保留“随机模拟”标记和全部六次三枚币原始结果。要另起一卦，请使用“新建系列”或原系列的“再起一卦”。

随机原理、概率与验证说明

本入口用系统随机数模拟三枚公平、独立的硬币。采用浏览器的 crypto.getRandomValues 提供强随机值，通常由系统熵源驱动的伪随机发生器产生；它不是实际投掷硬币，也不意味着具有预测能力。动画为留出专注时间，不参与随机数计算；没有据此证明念力能影响随机结果。开启系统“减少动态效果”时保留同样约 2 秒的等待时间，减少翻转动作。

数学模型：每枚阴面记 2、阳面记 3，设 X₁、X₂、X₃ 各以 1/2 概率取 0 或 1，且相互独立，则总数 S＝6＋X₁＋X₂＋X₃。故 P(S＝6＋k)＝C(3,k)／8（k＝0、1、2、3）。

结果对应爻象理想概率
6老阴1/8＝12.5%
7少阳3/8＝37.5%
8少阴3/8＝37.5%
9老阳1/8＝12.5%

不能把四种爻象各按 25% 随机选取后称为“三枚硬币模拟”；实物硬币也可能存在偏差。上表仅描述公平硬币模型，不代表本软件筹策法的概率。

概率分布可用数学和抽样检验核对，预测现实事件是否准确则要另做预先规定判断标准、对照基准并可重复的验证。已有易经相关实验，但所查资料不足以证明软件随机起卦能可靠预测现实事件；一项 200 人研究中仅第二卦命中率高于机会水平，且差异并不显著，也不能据此宣称实际预测准确率。

推荐使用太极丸、枚卜丸、蓍草与筹策进行实物起卦。随机模拟作为便捷选项，不能据此宣称预测准确率；录入、换算与排盘测试通过，表示程序步骤符合相应规则。

原理参考：W3C 随机值接口；Storm（2006）易经实验。

档案、导出与备份

“档案”按系列保存相关卦例。展开系列可打开各卦；背景保留来源，各卦分别保留问题、卦象、时间与分析。

结果页的“导出”菜单可导出本卦案例或诊断信息；系列卡片中可导出整个系列。“使用说明”顶部也可导出本说明，发给新人用浏览器打开。

案例和配置保存在当前手机。卸载、清除数据或换手机前先导出；目前导出用于留存和复盘，尚无一键恢复整个旧档案的入口。安装独立新版时，应保留旧应用查阅已有案例。

遇到问题，按现象查找

先看卡在哪一步，再决定是否重试。

报告整理超时

旧报告可先查看已保留的结论与“专业分析”，不必仅为这条提示重新解卦。新版在综合解卦完成后由本机整理报告。

AI 很久没有完成，或前面阶段超时

检查网络、厂商服务与账户额度，查看当前阶段和运行记录。高强度推理可能需要较长时间，可先保持应用在前台。

“刷新状态”不会重复分析。确认原任务结束后，再决定是否重新解卦；不要反复发起相同请求。

密钥、权限或模型错误
检查项要确认什么
厂商密钥与所选厂商一致，没有多余空格。
账户可用额度充足，已开通所选模型。
模型或接入点与厂商控制台配置一致，再保存模型设置。
回复格式未通过校验

应用会尝试修复并保留原回复；仍失败时，从结果页“导出”菜单保存诊断信息，并说明厂商、模型、卡住的阶段与时间。

尚未安装规则包

确认安装的是内置规则版。公开源码构建的版本需要在“规则 → 规则包”中另行导入规则包。

随机模拟点击失败，或者没有重新生成

如果提示系统随机接口不可用，请重新打开应用后重试。没有生成的那次不会加入记录。

六次完成后按钮锁定，切页、重开、保存和重新解卦都会沿用原结果。另起一卦请用“新建系列”或“再起一卦”。
