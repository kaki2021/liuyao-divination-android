# 新增原理审查与软件改进记录

审查日期：2026-09-19。

这次需要改进的是卜宅规则的适用范围、输入和解释，不是把原有权重统一改大或改小。已加入10条有出处的卜宅原理、专题输入和结构核对。原有70项实验参数保持逐字节一致。

## 怎么使用

1. 输入问题后展开“卜宅／选房专题”，勾选启用。普通问题可以不启用。
2. 选清本次阶段、阴宅或阳宅、谁起的卦、是否入住，填写针对谁、哪个地点、什么方案。可用称呼和地点代号，不需要完整地址。
3. 保存排盘后，在“专业分析”查看五地命名候选与条件核对。发起AI分析后，模型会接收本次适用的专题原理。
4. “规则库”中可切换“评分参数”和“卜宅原理”。参数继续导出为XLSX；原理及出处导出为JSON。两者都能在软件内导出，不需要另拿外部文件才能使用。

多个地点或方案分别建案。核对范围、诊断问题、验证整改方案也分别记录主问。前序案例编号仅用于用户关联，不会自动读取旧案或证明旧诊断成立。若解释需要旧案内容，请补充相关背景。

## 对照资料的改进

| 新原理 | 软件行为 | 没有自动认定的内容 |
| --- | --- | --- |
| 相对吉凶、个体适应 | 记录受益人、具体地点与方案 | 不把某地说成对所有人都好 |
| 相地与卜宅分工 | 记录已形成的使用或整改方案，再按主问分析 | 不把出生八字、罗盘或房型名当成已经起卦 |
| 分阶段治理 | 择地、核对范围、诊断、验证方案四种阶段 | 不把诊断卦当作整改有效，不自动重占直到吉 |
| 五地命名 | 从世爻六亲列命名候选及所需六亲，展示本卦／伏神、月令、空破 | 不拿最高分用神、元神或世身替换世爻 |
| 兼吉、独损、贪生忘克 | 展示出处与条件，限制AI解释范围 | 不从单一分数推断成局或同时生效的全部生克 |
| 起卦身份 | 区分主家本人、卦师独立勘察、其他代问 | 不因问“房子”就固定父母或世爻为用 |
| 阳宅选房偏好 | 仅对应主家本人选房，核对静动、六冲、六合、世爻日冲及实验暗动 | 静卦不直接叫静旺，日冲不一律叫暗动 |
| 尚未入住的世空例外 | 只在主家阳宅选房、未入住的场景提供“世旺”条件提示 | 不全局取消旬空分值，不自动宣布出空 |
| 装修诊断 | 与选房分开，提出待核对的问题方向 | 不把不利诊断直接改写为整套房屋不能用 |

五地映射如下。右栏的“旺相”仍需综合判断，并非普通月令分类或实验分越过某个阈值就算满足。

| 命名候选 | 持世六亲 | 另需核对 |
| --- | --- | --- |
| 亲丁地 | 兄弟 | 子孙旺相 |
| 丁财地 | 子孙 | 妻财旺相 |
| 财官地 | 妻财 | 官鬼旺相 |
| 官印地 | 官鬼 | 父母旺相 |
| 名望地 | 父母 | 兄弟旺相 |

例如父母持世，官鬼发动来生世，命名仍按“名望地”方向列候选，不能倒置成“官印地”。其他条件是否满足是另一层判断。

## 为什么这次没有再加0.5、1、2

新增资料给出的是定性关系与场景条件，没有规定数值权重。因此新增原理没有参数值，不虚构评分公式。原有70项参数仍是可修改的实验模型，含义、公式、示例和试算继续保留。

尤其“尚未入住且世旺时不因世空单独否定”是局部解释条件，不等于所有问题的EMPTY扣分应该改成0。软件保留原始实验分，同时向专题解释提供这个例外及其前提。当前还没有经过验证的“卜宅专用总分”或成功率。

## 尚待进一步完善

- 贪生忘克涉及作用目标和先后优先级。通用评分仍可能列出多向生克贡献，不能把每一项都视作同时确定生效。现在已明确提醒模型和专业读者；完整优先级算法需要更多明确例证。
- 真五行的适用范围及与六亲、旺衰的配合仍未形成完整可执行判据。新增风水资料不能据此让所有风水问题自动切换真五行。
- 兼吉、独损没有完整穷举条件，五地“旺相”也没有原文数值门槛；保留为条件解释，不自动定局。
- 资料提到一些应期原则，但不足以补齐完整应期算法，软件仍不推造精确入住或发力日期。
- 《太卜风水术》中的相地、墓穴规划、尺寸、排葬、符咒等内容不是现有六爻引擎已实现的功能。历史叙述、疾病比喻、地气和灾害主张也不作为已经验证的事实输入。实际建筑或环境问题需要现场材料核对。
