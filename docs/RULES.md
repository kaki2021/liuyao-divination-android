# 规则表与实验算法

## 规则来源

基础纳甲、卦宫、六亲、世应身位、普通五行关系和三形六害仍来自原项目资料与实现。本版没有改成其他流派常量。

新规则表的 70 行均标记 experimental。数值由初始模型拟定，不宣称出自《卜筮正术》原文。旬空采用日柱所属六十甲子旬的两支空亡；月破/日冲按支冲识别。识别到结构，不等于直接判定吉凶。

## 可编辑字段

参数值（旧表头 Value 仍兼容）、启用、来源、解释、备注为黄色列。Rule_ID、类别、名称、条件、单位、状态、类型与上下界属于系统字段。当前工作簿不依赖 Excel 工作表密码保护；导入器强制检查系统字段和完整 ID 集合。Rule_ID 被更改、缺失、重复或新增未知 ID 会拒绝整次导入。

Rules 工作表不接受单元格公式、非有限数字、数值列文本、越界值或无效地支。必要参数不可停用；偏弱分界必须小于偏强分界。导入失败不替换当前参数。

## 分数计算

每爻初始 5 分。默认月令旺/相/休/囚/死分别 +2、+1.5、-0.5、-1、-2；日辰同类、生、克、泄、耗分别 +1、+1.5、-1.5、-0.5、-0.5。再加旬空、月破、日冲等状态与动变修正。所有值可在规则表内修改。

第一轮只计算每爻自身日月和动变，保存 local_strength。第二轮从其他动爻或启用的实验暗动爻计算作用，其影响按来源局部分/10及空破衰减系数缩放。静爻之间只保留结构，不直接累加作用。最后保留 raw_score，并截断至 0–10，按可调阈值分为偏弱、中等、偏强。

整个过程不循环传播；不会用目标更新后的分数再次影响来源。来源空破既可以减少其局部分，也可乘以来源衰减系数，这是当前模型的两层设定，均可配置。

没有实际起卦时间时，日月、旬空、月破等值为未知，只计算动变及可见爻作用。分数明确记录为覆盖不全的局部分，不用当前时间补算。

## 动变与伏飞

变爻六亲使用本卦宫五行参照。回头生克以变爻对原动爻的五行方向计算，仅发动位置有动变作用。其他位置的变卦纳支仍属于结构，不能当成发动。

化进配对：寅卯、申酉、巳午、亥子、丑辰、辰未、未戌、戌丑；反向为退。每对可单独停用。

默认墓支：木未、火戌、土辰、金丑、水辰；默认绝支：木申、火亥、土巳、金寅、水巳。此处采用实验五行约定，尤其土的墓绝存在不同口径，均可在表内修改或停用；没有从阴阳天干十二长生表冒充推出唯一标准。

所需六亲不现时，从本宫纯卦同位置纳支计算伏神，飞神取当前本卦同位置。飞对伏的生克、伏神日月状态和实验分分别保存。伏神不自动变成暗动作用源。

## 取用与关系

同类多现按综合分、发动和持世加分排序；并列暂取较低爻位，同时保留并列候选，便于解释和反馈。原神生主用，忌神克主用，仇神生忌神。主辅权重只用于辅助功能对主目标的摘要，避免重复计入原先爻间分数。

三合和半合默认只识别主卦爻的组合，不自动判成化，也不自动加分。暗合和相破默认关闭；启用后采用表内列明的实验配对。三形、六害修正默认 0 分，避免仅凭标签判断好坏。

## 版本

版本号为规则规范和完整参数内容的 SHA-256 摘要前缀。数字 1 与 Excel 返回的 1.0 规范化为同一数值；未改内容的导出再导入保持相同版本。任何有效参数、启用或解释文字的变化都会形成新版本。

每次分析同时保存完整参数快照；反馈从所选分析读取版本。可在同一案例导入不同版本后重新解卦并回看两次记录；独立统计与 A/B 对比界面留待后续。


## 先看懂数字，再修改

这些数字是相对权重，没有声称来自原典的固定计分，尚未用足量实际案例校准。

| 参数种类 | 0.5、1、2 如何理解 | 例子 |
| --- | --- | --- |
| 直接加减分 | 加半分、加一分、加两分；负数扣分 | 5 + 2 = 7 |
| 来源乘数 | 一半、原量、两倍（仍受每项上下界约束） | 来源 6 分，生扶权重 1，旬空乘数 0.5：1 × 6/10 × 0.5 = 0.3 |
| 动爻作用权重 | 还要乘来源强度，不是直接加在目标上 | 权重 1 × 来源 6/10 = 0.6 |
| 强弱分界 | 只控制偏弱、中等、偏强标签 | 偏强分界 6，得分 6 是中等，超过 6 才偏强 |
| 候选排序加分 | 用于候选排序，不修改爻强度 | 综合分 6 + 发动排序 1 = 排序 7；原综合分仍为 6 |
| 识别开关 | 参数值 1 为占位；通过“启用”列控制 | 三合识别不直接加分；化进识别后才应用 ADVANCE |
| 地支参数 | 是判定时对照的地支，不是分数 | 变爻命中指定墓支，才应用 CHANGE_TOMB |

负数从 −1 改成 −2，是扣得更多；从 −1 改成 −0.5，是扣得更少。0 分意味着该项不计分，不能把它解释为百分之零的概率。

软件侧栏“规则库”中，70 项参数均有独立解释。可以搜索参数、修改试算值并比较六爻分数、强弱与伏神；该操作不会保存参数。排序、辅助摘要和结构开关未必改变分数，此时应对照公式理解，而不能仅看六爻总分推断没有作用。

正式修改仍通过导出 Excel → 修改 Rules 黄色列 → 保存 → 校验导入。Guide 提供阅读指南，试算页有可编辑演示输入与公式引用。演示输入不被导入；软件只导入 Rules 参数。导出后用 Excel 打开会重新计算示例公式，避免把初始模板缓存当成当前参数结果。

每次先改一项，观察差异，再用实际案例反馈检验。此次只补说明和试算，内置初始权重未更改。
