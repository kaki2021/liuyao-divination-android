# 压缩包检查与命名约定

交付文件使用“六爻占问软件.zip”，解压后的目录为 liuyao，不使用 V5 等软件发布编号。软件仍处于初始开发阶段。规则内容的摘要编号、数据库结构编号与历史记录继续用于核验和追溯。

本次发现上次交付的 ZIP 已被截断，末尾的中央目录及结束记录缺失，因而无法正常解压。当前包从完整源码重新生成，使用标准 ZIP Deflate 格式、ASCII 内部路径，并在关闭文件后检查 CRC、完整解压和逐文件摘要。

公开源码包不再内置真实规则表、编译规则或历史版本。应用可以启动并进入规则页，但首次排盘前必须导入由维护者单独分发的 `.lyrules` 加密规则包；也兼容直接导入 XLSX。加密包与口令应分开发送，不得放入公开 ZIP、APK 资源或 Git 仓库。

导入成功后，编译规则写入应用私有数据目录的 `knowledge_base/`，不回写程序目录。历史分析继续保存其当时的规则版本和快照。
