# 功能与实现说明

## 启动兼容性修复

修复旧人物表缺少 is_self 时无法启动；迁移前自动备份，按实际字段补列，事务失败回滚；人物新增改为按列名写入，兼容旧表列顺序。详见 MIGRATION.md。

## 已实现

- 修复 `report_generator.py` 的语法错误、字符串结论与前端对象契约不一致、重复拼接等问题。
- 预测审计分离：引用缺失、关系解释方向、依据范围等进入独立 warnings；JSON 无法解析、结构类型错误和跨案例绑定仍可阻断并修复一次。
- 恢复原来被提前 return 跳过的审计检查，保留原回复、规范化输出、审计意见和致命错误。
- 统一报告链：interpretation → report → user_report。固定七节，默认显示结论，研究信息另行折叠。报告整理失败则保留 interpretation 的结论并用程序排版。
- 新增 70 项可配置参数的规则知识库：Excel 导入导出、严格导入校验、摘要版本和规则快照。
- 将日月、动变、强度和关系作用模块接入排盘及 AI 事实输入。
- 增加旬空、月破、日冲、实验暗动/日破、变爻六亲、回头生克、化进化退、墓绝空和化月破。
- 缺失六亲按本宫纯卦定位伏神和飞神，记录伏飞关系、日月状态和实验分。
- 增加六冲、三合/半合结构；暗合、相破用独立实验开关，默认关闭。三形和六害沿用原体系。
- 取用增加主用、辅助候选、同类多现排序、伏神候选、原忌仇神，以及辅助功能作用摘要。并列位置完整留存。
- 新增持久化人物档案和本人默认选择；八字仅记录，模型输入不含档案出生信息。
- 分析结果绑定 rules_version、parameter_version、engine_build、模型、参数快照、用户报告和审计报告；反馈绑定具体分析和规则版本。
- 旧取用缺口保留在审计，已解决部分从后续 AI 当前上下文移除。
- 新增规则库、人物档案、综合分明细和反馈字段界面。
- 压缩包内部使用 ASCII 路径，提供原文件名对照。

## 测试调整

原有“语义审计失败必须拒绝预测”的测试，改为“保留预测并保存警告”；原有成功分析 `partial` 改为 `completed`，表示流程完成，不代表预测已验证。JSON、类型、选中候选、跨案例绑定、所有权、历史快照和基础排盘测试继续保留。

新增测试实际覆盖全部 4096 个四态六爻组合；并验证 Excel 往返、非法规则输入、规则改分、旧预测不变、伏神取用、人物快照隔离、八字排除和 原数据库迁移。
