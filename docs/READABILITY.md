# 本次改动

1. 出生日期自动推算八字：使用本机内置历法，不调用 AI。未知时间只排确定的三柱，交节当天提示补时刻。按北京时间、立春换年、节令换月、零点换日；晚子时时柱按次日子时，不做真太阳时或历史夏令时换算。保存档案时服务端重新计算，避免页面显示与保存值不一致。出生信息仍不进入六爻 AI 输入。
2. 报告分两层：通俗答案直接回答问题，列出现实注意事项、行动和时间；专业分析保留七部分依据。生成报告时校验通俗判断方向与原推演一致；发现六爻术语或实验评分会要求重写，失败则保留已有预测并给出简要答案。历史报告不重写，原文仍在专业页。
3. 结果分为直接答案、专业分析、卦盘与计算、分析记录。专业页再分七个主题。补充说明移到后续反馈，桌面和手机页面均可使用。
4. 规则库的 70 项参数均有独立含义、公式、修改影响、示例与初始取值考虑。软件内可单项试算；导出的 Excel 自带 Guide 与试算页。0.5/1/2 区分加减分、乘数、分界值、排序和开关。所有初始参数值保持原样。

## 使用当前压缩包

关闭旧程序，完整解压到新的文件夹，再运行 start.bat 或 Liuyao.exe。Windows 默认继续读取原有的 %LOCALAPPDATA%\Liuyao 数据，不需要删除数据库。自定义过 LIUYAO_HOME / LIUYAO_DATA_DIR 的电脑应继续沿用原设置。

已有预测的完整通俗报告需要点击“重新解卦”生成一次新分析；会使用已配置的模型，并保留原分析。设备上已经安装的规则继续生效，无需重复导入；导出时自动带上新版解释模板。

包含此前启动修复：为缺少 is_self 的表补字段；对用户提供的 profile_id/slug/details_json 旧式空人物表，备份后保留旧表并创建新结构。旧式人物表若已有资料则保护性停止，避免猜测转换含义。案例、预测和反馈不删除。

包名不附软件版本编号。内部规则内容摘要和数据库结构编号仅用于一致性校验与历史追溯。
