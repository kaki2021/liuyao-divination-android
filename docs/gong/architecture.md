# 架构与数据边界

## 当前组合测试版

- Android 原生壳负责 WebView、权限、相机与文件选择、定位、通知等系统能力。
- 界面使用 HTML / CSS / JavaScript，通过同一设备上的本地 HTTP 接口与 Python 服务通信。SQLite 持久化人物资料；部分历史或其他技能各有独立存储，不应假设均包含在人物档案中。
- 人物 UI 状态含自我资料、名片、联系人、动态、记录等；服务端有版本号与写入幂等保护。AI 建议先展示给用户审核，再经专门接口写入。
- 名片分享仅应包含用户对该卡选中的字段；私人关系、交流记录、约定不应随名片分享。
- 对模型服务发送的数据取决于用户选择的模型和当前请求；不得承诺 AI 全程离线。

## 供代码审阅的参考快照

`reference/` 包含结构化资料 UI、人物助手、交流记录 UI、离线名片、V0.9 状态服务和定位结果格式化器。它们是构建过程组合进 APK 的源码片段，引用宿主模块及本地接口，不能直接当作完整应用构建。文件顶部或相关测试可用于追踪接口和字段；完整组合构建暂未公开。

## 安全与隐私

- APK 和公开仓库不是秘密存储；避免打包秘密，审查任何公开文件。当前完整测试 APK 带有私有业务规则，不能假定分发 APK 后这些规则仍不可提取。
- 人物数据属于敏感个人信息；数据使用应遵循授权和最小化原则。资料字段例如家庭和情感状态均为选填。
- 模型凭据、私有规则、签名密钥、备份密码和真实资料不要提交仓库。公开分支不含用户的私有规则包或口令。
- 当前人物资料手动备份为未加密 JSON；仅涵盖人物 UI 状态，并非设备或所有技能的完整镜像。
- 设备权限与后台提醒效果依赖 Android 版本和厂商限制，需要真机验证。
