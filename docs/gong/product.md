# 知人 Skill：人物档案、名片与交流

## 设计原则

1. 一份个人完整资料可选择性生成多张名片，用户决定每张卡展示哪些信息。
2. 联系人资料与仅本人可见的关系、交流记录和约定分开；选项提供启发，也允许按需填写。
3. 首页 AI 可整理长段人物资料，提出字段及记录建议，由用户逐项核对、选择后保存。
4. 尽可能本地存储；对外分享、扫描、定位与提醒由用户主动操作或授权。

## 测试版已有的主要界面与路径

- 个人资料分基本信息、职业与技能、生活与兴趣、个人简介与经历、目标与合作；分组可折叠，技能和兴趣有分类选项，可编辑自由文本。工作和教育经历提供填写提示。
- 多张名片可选字段和对象，支持离线二维码；支持相机扫描、头像拍照。漫画风格处理未接入。
- 联系人资料包括多项职业、行业、企业等；个人关系分类、交流记录、约定单独管理。点击联系人可查看相关资料与记录。
- 人物助手可将自由文本转换为待核对的资料和记录，支持新建人物或更新现有对象；模型配置需要用户自行提供可用服务。
- 联系人生日提醒需要系统通知授权；请在真机上核验各系统的后台行为。
- 地点字典和输入建议用于辅助选择；定位要用户同意。新版尽力显示定位服务提供的中国区县，服务未返回区县时保持市级或更粗粒度，用户可手动修改。
- 企业建议不保证全面或实时，不等同官方工商登记查询；中国工商数据未接入商业接口。
