# 工：面向个人的 AI 技能平台

“工”想做的是一个可以不断增加能力的个人工具：以统一的对话入口和基础资料为底座，把**六爻占问、知人人物档案、知识库问答**等能力组织成相对独立、可复用的 Skill。用户按任务使用能力，开发者可以逐步完善单个 Skill，而不必每增加一种功能就重新做一个完整软件。

目前已有 Android 组合测试版：它把六爻、人物档案、知识库相关能力和统一对话入口组合在一起。平台与 Skill 的划分已开始落地，但**通用插件安装、跨 Skill 自动协同和完整独立运行仍是设计目标**，不是已完成的通用系统。

## 实现状态速览

| 能力 | 当前状态 |
| --- | --- |
| 六爻占问 | 有起卦录入、确定性排盘、规则与模型分析、案例和追问；具体体验与边界见六爻文档 |
| 知人 | 有本地人物档案、名片、记录及 AI 审核整理等测试版功能 |
| 知识库问答 | 有 Dify Cloud 适配与引用相关实现；需要用户配置并授权，真实服务是否可用取决于环境 |
| Skill 组织 | 已有技能说明、部分 manifest、固定技能登记与专用路由；并非通用可安装 Skill 平台 |
| 反馈 | 有反馈记录 / 分诊思路与实现；APP 不会自主修改自身代码 |
| 云备份、跨 Skill 周报 | 规划中，尚未接通 |

> 公开分支是在较早的六爻 Android 源码之上补充说明和部分较新代码快照，**不是最新测试 APK 的完整可复现源码**。组合构建仍依赖非公开组件；不要把私有规则、口令、真实数据或签名材料提交到公开仓库。测试 APK 包含私有业务规则，分享安装包可能使其被提取。
