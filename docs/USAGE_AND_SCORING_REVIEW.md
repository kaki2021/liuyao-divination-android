# 使用引导与评分说明核查

核查日期：2026-09-20。本说明对应本包源码，不代表已完成安卓真机或线上模型验收。

## 原文核对结论

已通过用户指定的 Google Drive 读取《卜筮正术.docx》和《卜筮正术补充卜宅.docx》的可读正文，核对相关课次与前后段落。核对记录见 `software_prep/reading_review.json`，含原件链接、课次、短引、采用说明及所读取正文的摘要；不是原始 DOCX 字节校验值。既有 B 编号是原文块索引，不是印刷页码。

《卜筮正术》001 序言“三、巫术与道术的融合”明确使用“谋而后卜”，要求先认真谋划，再占计划中的未决部分；判断不利时审视计划，查漏补缺后可再占。原文还明确否定泛泛问一年或一生财运的意义。因此不能仅概括成“有疑问就可以随便问”。

对于谋事、比较方案，用户提出的“已有行动方向，再通过卜筮定夺”更接近原文。但“已有方向”不表示方案已经完善、只能问是否照办，原文同样强调检查和改进计划。对尚在排查范围、诊断问题的主问，不能强制预先编出治理方案；044 的治风水流程本身就是先定位和诊断，再拟定并问整改方案。

001 说明目的在发现和解决问题、改进做法；010 强调真念由本人清楚表达，反对猜来意，并以“慎和畏”要求断语有责任；011 强调按具体用途取用、一个爻不自带固定吉凶；012 区分得失与成败及社会角色和个人身位。003 也解释多个候选分别占问的枚卜原则。这些整理为九项可展开的原理说明，原文短引、课次与软件组织方式分别展示。

运行时 intent 提示词同步采用上述提问边界，文件在 `liuyao_app/runtime_contract.py` 的 `INTENT_INSTRUCTION`。主问、功能或计划及关切已清楚时直接继续；结合所有背景仍无具体所指的泛问，最多补问一个必要现实问题，不伪造行动方向。问法规范不等于要求填写完整策划书或专业术语。研究用历史 prompt pack 保留作资料，生产请求以 `runtime_prompt()` 生成内容及运行审计记录为准。

## 卜宅四项怎样选择

择地／选房是独立场景，不要求所有人依次占四卦。治理已有问题时，044 则明确要求依次核对范围、另卦诊断具体问题、再另卦验证整改方案。可以记录已开展到的阶段，但须说明前序依据，不能选一步就声称三步已完成。

| 选项 | 什么情况下选 | 本次主要回答 | 应填写什么 |
|---|---|---|---|
| 择地／选房 | 有具体备选地点和使用计划 | 指定对象按该方案使用这个地点是否适合 | 谁、哪个地点、怎样使用 |
| 核对问题范围 | 有具体困扰，尚不清楚是否沿宅地或布局方向排查 | 是否从这个范围继续查起 | 已知现象、想核对的范围 |
| 分析具体问题 | 前一步已核对待查范围，再另起一卦 | 优先检查哪些具体环节 | 具体问题、已知现象和范围 |
| 验证整改方案 | 已诊断问题并拟定具体措施，再另起一卦 | 该措施是否有利于本次目标 | 改哪里、怎样改、解决什么问题 |

选择后立即显示适用场景、主问、问法例子、下一步，输入框随阶段给出提示。教学例子不会自动填入案例或发给 AI，切换阶段不会覆盖用户已填内容。场所类型、实际起卦人、入住情况、受益人和前序案例都有说明。关联旧案编号不等于读取了旧案全文。

“核对范围”不证明现实因果，“分析问题”不证明某个缺陷真实存在；“验证整改方案”在此表示对拟定方案的占问，实施后的真实效果另记反馈。

## 初始 5 分到底是什么

每个爻分别有一份实验相对强度，六个爻各自从相同基础值开始；伏神另算。没有六爻相加的整卦总分，也没有将分数转换为事情成功率。

0～10 是软件选定的量尺，5 是居中的计算起点，给加减分预留空间。现有材料没有足量案例校准，无法证明 5 比 4 或 6 更准确，也无法声称这是原书规定的分值。

仅演示一个爻的自身加减：5（起点）＋2（月令旺）＋1.5（日辰生）－1.5（旬空示例扣分）＝7。这个例子不代表当前案例；具体命中和分值在“查看实际计算”中读取。

### 实际公式

设 clamp(x) 为把 x 限定到 0～10，B 为基础分，Cᵢ 为某爻自身各项贡献：

1. 局部分 Lᵢ = round(clamp(B + ΣCᵢ), 3)。自身项包括按实际命中计入的日月、空破、发动和动变；缺少日期时不补造日月。
2. 来源系数 Fⱼ = Lⱼ ÷ 10 × 旬空系数 × 月破系数 × 暗动系数。未命中状态的乘数为 1；普通静爻不作为主动来源。实验暗动来源才乘暗动系数。
3. 每一项外来贡献 = round(该项爻间作用权重 × Fⱼ, 6)。识别到的生克及其他关系修正分别计算；停用参数计 0。
4. 最终分 Sᵢ = round(clamp(B + ΣCᵢ + Σ外来贡献), 3)。这里用自身未截断的贡献合计，不把局部分当作新的起点；来源强度只用第一轮局部分，不循环传播。
5. 分数低于 LEVEL_WEAK 为偏弱，高于 LEVEL_STRONG 为偏强，中间及等于边界为中等。
6. 同类候选排序分 = 综合分 + 命中的发动排序加分 + 命中的持世排序加分。它不再加回爻强度。
7. 伏神分 = round(clamp(B + 日月空破贡献 + 飞生伏／飞克伏贡献), 3)。辅助摘要 = 方向 × 辅助综合分÷10 × AUXILIARY_FACTOR × MAIN_FACTOR，仅摘要，不重复计分。

界面读取计算引擎已有贡献，逐爻列出共同起点、自身项、来源乘数、外来项、原始合计、0～10 边界与强弱标签。显示合计保留三位小数。

### 同一个数值因类型而不同

| 类型 | 0.5、1、2 的含义／影响 |
|---|---|
| 共同起点 | 每一爻独立计算的起算值 |
| 条件加减分 | 条件命中后加 0.5、1、2 分；负数扣分 |
| 爻间作用权重 | 还须乘来源系数；来源为 6 分、无衰减时，权重 1 实际贡献 0.6 分 |
| 来源衰减乘数 | 0.5 保留一半，1 保持，2 为两倍；实际允许范围以该项校验为准 |
| 强弱标签分界 | 改标签边界，不直接改分数 |
| 取用候选排序 | 同类候选排序加分，不改爻强度 |
| 辅助摘要乘数 | 改辅助作用摘要，不重复计入强度；负值反转方向没有已验证依据 |
| 结构识别开关 | 数值 1 是占位，改“启用”，不表示加 1 分 |
| 地支对照约定 | 选择化墓／化绝所对照的地支，命中后应用另一个分值参数 |

## 如何修改才有依据

正常使用不要求调参。先找出明确的模型问题，写下希望修正的现象；查看命中条件和账单，只改一项，试算前后对照，再用多例真实反馈比较。只让某个案例分数变高，不足以证明更准确。

“试算”不保存、不更改历史案例、不调用 AI。实际保存仍使用已有规则导入流程；请先导出留存原表。评分参数页新增按九类筛选，每项说明影响位置、公式、初值考虑、修改方向和试算。非计分项会说明为何分数不变；结构开关和地支约定另显示识别结果对照。试算未执行 AI 取用，不能伪造本案取用结论或主辅角色。

导出的 XLSX 同样新增“参数类型”“影响位置”，并保留说明、公式、修改影响、示例和初值考虑。导出后可重新导入，数字与启用状态不因此改变。
